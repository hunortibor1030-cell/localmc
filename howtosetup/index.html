How to setup?

To set up, you need to install java 17.

1. Download

To download it, go to https://hunortibor1030-cell.github.io/localmc, then download a version.

2. Extract & run

To install plugins, extract the .zip and go to the MinecraftServer folder, and place the plugins to the plugins folder. To run and join the server open the run.bat/run.sh file and minimize the terminal, then open minecraft multiplayer direct connections and type in localhost.
